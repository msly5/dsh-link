# 工作区分组与会话归档

侧栏按 DSH 桌面端的工作区归属展示会话，点击文件夹标题可以展开或收起。一个分组先展示最近 5 项，更多会话可进入“查看全部”；“对话”页默认按工作区分组，也能切换到按时间分组。搜索保留分组，未归属工作区的会话进入“未分组”。目录暂不可用时，列表保留按目录查看及重试入口。

点击会话右侧的省略号或长按会话，选择“归档会话”。归档会话会从普通列表移入侧栏“已归档”，保留历史和工作区归属。可以在归档列表的菜单或会话详情底部恢复。运行中或仍有后台活动的会话需要确认停止后才能归档；客户端不会自行重试为强制停止。

归档使用 DSH `workspace/archiveSession` / `workspace/unarchiveSession` 接口，归档集合取自 `workspace/follow`。手机收到服务端成功响应后才更新本地显示；失败保留原列表。恢复会话不会改写其原工作区。切换服务器时清空归档与工作区状态，旧请求不能写入新服务器的列表。

## 验证（1.0 / build 5）

- 68 项客户端核心测试通过，包含工作区权威归属、同名目录、未分组、归档 / 恢复请求、禁止隐式停止、错误码和缺失响应的回归。
- iPhone 13 Pro / iOS 27.0.1：独立 Debug 预览中完成归档、查看归档、恢复后回到原分组、运行中归档确认、分组展开 / 收起及按时间切换；查看浅色、深色和辅助功能大字号。归档详情页恢复后重新显示输入框，可继续对话。本次测试的手机预览及控制任务已停止。
- 真实连接读取到了桌面工作区分组；公网探测验证目录和归档接口的格式。不使用真实会话做归档写入测试：不存在的会话归档被拒绝，幂等恢复没有改变原归档集合。
