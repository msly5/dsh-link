# iPad 布局

构建：1.0 (6)。iOS 17 / Swift 5 保持不变，App 设备类型包含 iPhone 和 iPad。

## 行为

- 常规宽度且窗口宽度至少 820 pt 时，默认展示 320 pt 的工作区 / 会话侧栏；选择会话后侧栏保持打开，聊天仍可直接操作。
- 工具栏按钮可以隐藏或重新打开侧栏。窄窗口采用可滑动抽屉，选择会话后收起；iPhone 继续采用此布局。
- iPad 支持四个方向，允许系统多任务窗口。布局随窗口宽度变化，不依赖设备型号。
- 旋转、调整宽度和收放侧栏不替换聊天视图，保留当前聊天及尚未发送的输入。切换到另一个会话仍遵循原来的会话生命周期。
- 消息阅读区域和输入区域最大宽度为 760 pt，居中排列；欢迎页在较矮窗口内可滚动。
