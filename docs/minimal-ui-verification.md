# 简洁界面与深色外观验证

项目现名为 dsh link。以下旧构建记录和截图保留当时的 dsh remote 名称；当前界面截图见 README。

日期：2026-10-23。

采用暖白背景、黑灰文字、细线图标和平面列表。侧栏提供最近对话、所有对话、桌面工作区、连接设置与新建对话；主页面向右滑出时保持当前聊天视图挂载。聊天页简化消息和输入框样式，执行记录默认折叠，图片、模型、权限、审批和提问入口保留。

设备：iPhone 13 Pro，iOS 27.0.1。构建：1.0 (1)，独立签名的 `dsh remote 预览`，使用虚构数据验证 UI，与日常客户端并存。

- 已签名、安装并打开新版；控制通道可直接操作。
- 侧栏切换最近对话、桌面工作区与工作区内的对话列表；新建对话页打开与取消。
- 执行过程默认收起，点击后展开两项执行记录，再次点击收起。
- 输入文字与键盘弹出：消息输入框、模型和发送按钮位于键盘上方。
- 修复从列表边缘拉开侧栏、从侧栏向左收起时同时触发会话行的问题；相同左右滑动流程在真机复测通过，停留在原列表。

## 本次验证限制

本次真机使用独立预览构建，未连接真实 Mac 后端；实际消息发送、图片上传、审批、提问与 APNs 未重新验收。UI 交互通过不能代表这些联网流程已经通过。

## 安全复现截图

仅 Debug 构建支持以下启动参数：

```text
--no-push --ui-preview
--no-push --ui-preview --preview-sidebar
--no-push --ui-preview --preview-chat
```

可追加 `--preview-large` 检查大字号，或分别使用 `--preview-conversations`、`--preview-workspaces`、`--preview-new`、`--preview-settings` 检查其他页面。

预览使用固定的虚构工作区和会话，不连接 DSH、不发送消息、不创建真实会话、不保存最近会话、不读取连接凭证。预览中的连接设置禁止保存、清除或测试，模型选择不向服务器提交。Release 构建不启用这些预览开关。

## 深色外观补验

构建：1.0 (4)，iPhone 13 Pro / iOS 27.0.1，独立 Debug 预览 App。

- 移除正式界面强制浅色设置，颜色资源包含浅色与深色两套外观，由系统选择；聊天、侧栏、设置、弹窗、表格、输入框和按钮使用同一组动态颜色。
- 真机分别使用 `--preview-dark` 与 `--preview-light` 检查固定的虚构数据。已查看深色欢迎页、侧栏、聊天与表格、连接设置、新建对话、模型选择，以及浅色聊天回归；深色大字号聊天的文字和输入控件可读。
- 文字、次要文字、警示文字与主要按钮在对应背景上的静态颜色对比度均超过 4.5:1。签名设备 Debug 构建通过。
- 预览参数仅在 Debug 生效。此次未切换用户手机的系统外观，也未重新验证真实联网流程。
